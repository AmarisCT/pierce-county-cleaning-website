# Search (SEO)

What the site does for search engines, and the few settings you fill in. The off-site work (Google Business Profile, directories, reviews) is in the Local SEO Playbook doc.

## Built into every page

- A unique title, description and canonical link. Link previews (Open Graph) use `assets/og-image.jpg`.
- Structured data (schema.org JSON-LD), generated by `build.js`:
  - **Home:** `LocalBusiness` (name, service areas, email, price range, services with prices) and `WebSite`.
  - **City pages:** a `Service` for house cleaning in that city.
  - **Deep cleaning and move-out pages:** a `Service` with that service's price range.
  - **Every page except home:** `BreadcrumbList`.
  - **Pages with questions:** `FAQPage`.
  - No ratings or reviews are ever added to structured data. Google requires them to be real and shown on the page.
- Prices are written into the HTML at build time, not only added by JavaScript, so search engines and AI assistants can read them.
- Photos have width and height set, so pages don't jump while loading.
- `sitemap.xml` lists every page except the 404 page, with the date each page last changed. `robots.txt` points to it.
- The footer links to every city page and service page.

## Settings: `src/seo.json`

| Setting | When to fill it in |
| --- | --- |
| `googleSiteVerification` | Google Search Console → Add property → **URL prefix** → `https://amarisct.github.io/pierce-county-cleaning-website/` → HTML tag. Paste only the `content` value. |
| `bingSiteVerification` | Only if you add the site to Bing Webmaster Tools by meta tag. Importing from Search Console doesn't need it. |
| `addressLocality` | The city your Google Business Profile uses (with the address hidden), so the website and profile match. |
| `sameAs` | Links to your Google Business Profile, Yelp, Nextdoor and Facebook pages once they exist. |

After any change, run `node build.js && node tests/run.js`, commit, then publish (Actions → Deploy site (manual) → Run workflow).

## Adding a city

1. Copy a city page to `src/pages/house-cleaning-<town>.html`. Rewrite it for that town: neighborhoods, ZIP codes, what's useful to know there.
2. Set `<!-- city: Town -->` and `<!-- crumb: Town -->` at the top.
3. Add the town to `AREAS` in `build.js`, which adds it to the footer and to the business's service areas.
4. Add it to `service-areas.html`.
