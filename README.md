# pierce-county-cleaning-website

Official website for **Pierce County Cleaning Services LLC** — *Clean Spaces, Clear Minds.*
Residential and small-business cleaning in Tacoma, Puyallup, Lakewood, Spanaway and nearby Pierce County communities.

**Design:** "Stone & Linen" — warm stone background, condensed serif capitals (Instrument Serif), Jost for body text, thin ink rules between full-width sections, and photo-led panels. Photos go in `src/assets/photos/`; see [docs/photos.md](docs/photos.md).

> **Status: published on GitHub Pages.** See the live site at https://amarisct.github.io/pierce-county-cleaning-website/. Track outstanding business setup and launch follow-ups in [docs/launch-checklist.md](docs/launch-checklist.md); publication does not mark those items complete.

## What's here

| Path | What it is |
| --- | --- |
| `src/pages/` | Page content (one HTML fragment per page, with title and description at the top) |
| `src/assets/config.js` | **Edit this first:** phone, email, quote form endpoint, show/hide prices |
| `src/assets/prices.js` | Draft launch prices and add-ons used on every page and in the quote estimator |
| `src/assets/site.css`, `site.js`, `quote.js` | Styles, shared behavior, quote form |
| `src/assets/photos/` | Your photos, named by slot (see docs/photos.md) |
| `build.js` | Builds the finished site into `site/` (no dependencies) |
| `site/` | Built website, ready to host. Don't edit by hand; edit `src/` and rebuild |
| `internal/pricing-calculator.html` | Private job-profit calculator. **Not part of the public site** — open it locally |
| `docs/` | Pricing, compliance notes, booking tool comparison, launch checklist |
| `tests/` | Checks for the price estimator and the built pages |

## Making changes

You need [Node.js](https://nodejs.org) 18 or newer.

```bash
# 1. Edit files in src/
# 2. Rebuild the site
node build.js
# 3. Run the checks
node tests/run.js
# 4. Preview locally, then open http://localhost:8080
npx --yes serve site -l 8080
```

To set your domain in canonical links and the sitemap: `SITE_URL=https://yourdomain.com node build.js`

## Quote form, quote emails and invoices

Free, with no paid form service. The quote page shows an instant estimate from `prices.js`. When `quoteEndpoint` in `config.js` is set to your Google Apps Script web app, each request:

1. is saved as a row in your **PCCS Quotes** Google Sheet,
2. emails the customer a quote listing the service, home size, each add-on and the total (recalculated by the script, so it can't be tampered with),
3. emails you an alert with everything they entered.

After the job you send the invoice from the Sheet's **PCCS** menu. Setup takes about 15 minutes: [docs/quote-email-setup.md](docs/quote-email-setup.md).

| Path | What it is |
| --- | --- |
| `apps-script/Config.gs` | Your settings: phone, payment instructions, limits |
| `apps-script/Code.gs` | The script. Generated by `node build.js` with the same prices as the website; don't edit by hand |
| `src/apps-script/Code.template.gs` | Source for `Code.gs` |

While `quoteEndpoint` is empty, nothing is sent: the customer sees their request formatted to copy and text or email you. The form asks customers **not** to type door or alarm codes.

## Publishing

The site is live at **https://amarisct.github.io/pierce-county-cleaning-website/**, served by GitHub Pages from the `gh-pages` branch (Settings → Pages → Source: Deploy from a branch → `gh-pages` / root).

Changes pushed to `main` do **not** go live on their own. To publish them:

1. Go to the repo's **Actions** tab → **Deploy site (manual)** → **Run workflow**.
2. It builds the site, runs the checks, and copies `site/` to the `gh-pages` branch. GitHub updates the live site a minute or two later.

To move to your own domain later: run the workflow with your domain as the site URL, add the domain under Settings → Pages → Custom domain, and point the domain's DNS at GitHub Pages.

## Ground rules for site content

- No testimonials, reviews, ratings, certifications or "insured and bonded" claims until they are real and documented.
- Keep the business name exactly **Pierce County Cleaning Services LLC**.
- Routine house cleaning invoices carry no Washington sales tax. Don't add a sales-tax line to the site's prices.
