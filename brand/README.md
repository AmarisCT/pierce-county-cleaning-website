# Pierce County Cleaning Services — logo files

The logo is a single-line Mt. Rainier over the name, set in the website's type (Instrument Serif capitals, with tracked sans capitals beneath). The lettering is converted to outlines, so the files look the same everywhere with no fonts needed.

The `brand/` folder isn't published with the website. It's here to download when you need a logo somewhere else.

## Which file to use

| Where | File |
| --- | --- |
| Google Business Profile, Yelp, Nextdoor, Facebook, Instagram (profile picture) | `pccs-icon-1024.png` (crop-safe for round profile pictures) |
| Stripe → Settings → Branding → **Icon** | `pccs-icon-1024.png` |
| Stripe → Settings → Branding → **Logo** | `pccs-logo-horizontal.png` |
| Stripe brand color / accent color | `#2B2926` / `#ECE8E2` |
| Documents, flyers, quotes on light paper | `pccs-logo.png` (transparent) or `pccs-logo.svg` |
| Dark backgrounds, shirts, car magnets | `pccs-logo-light.png` or `pccs-logo-light.svg` |
| Email signature, letterhead, wide spaces | `pccs-logo-horizontal.png` |
| Print shop (any size) | the `.svg` files |

`pccs-logo-on-stone.png` is the full logo on the website's stone color, with margin, for sharing as an image.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#2B2926` | Logo, text |
| Stone | `#ECE8E2` | Background |
| Paper | `#F5F2EE` | Cards, emails |
| Dark | `#3A3632` | Dark sections |
| Muted | `#66605A` | Slogan, small text |

## On the website

The header uses `src/assets/logo.svg`, and `src/assets/logo-row.svg` on phones. The browser tab icon is `src/assets/favicon.svg`, and the home-screen icon is `src/assets/apple-touch-icon.png`. Search engines get `src/assets/logo-square.png`.

## Rules

- Keep the name exactly **Pierce County Cleaning Services**. Don't stretch, recolor or add effects.
- Leave clear space around the logo at least as tall as the words "CLEANING SERVICES".
- Use the dark logo on light backgrounds and the light logo on dark ones.
